# CNG 城市排水管网生成

## 启动

解压整个软件文件夹，双击 `SWMManywhereStudio.exe`。请勿仅复制 EXE，`_internal` 是必需的运行环境。

支持 Windows 10/11 64 位。软件包含 Python、GIS 依赖、WhiteboxTools 和固定版 WebView2；无需另行安装 Python。
首次启动需要加载桌面与地图组件。新区域的底图、高程、建筑和 OSM 道路/河流数据需要联网。

窗口名称为“CNG 城市排水管网生成”。左侧直接从项目名称和坐标开始，右侧主要空间用于地图；程序文件名及数据目录沿用旧版，因此原成果和地图位置可继续使用。

## 使用

1. 启动后进入不含管网项目的“主地图”。在地图上拖动、缩放，点击“框选范围”，按住鼠标画出矩形。
2. 或填写西侧经度、南侧纬度、东侧经度、北侧纬度，点击“应用坐标并定位”。坐标为 WGS84 十进制度。
3. 填写项目名称，点击“生成管网”。地图下方显示百分比、当前步骤和已用时间。
4. 完成后，管线和排口叠加到地图。右上角可开启节点图层；点击管段查看编号、管径等已有属性。
5. 选择导出格式，点击“导出成果”，通过保存对话框选择位置。推荐导出 SWMM 模型包，解压后用 SWMM 打开 `.inp`。
6. 历史项目下方可“重命名”或“删除”；删除时会询问“是否同时清除缓存”，默认保留缓存。确认删除会移除该项目的模型、图层、日志和历史记录；运行或暂停中的项目需要先停止并取消。
7. 点击地图右上方“主地图”可收起所有管网，继续选择新的生成范围。未选择历史项目时，不会自动加载以前的管网。

一次生成一个任务，暂停的任务也占用这个名额。等待时可浏览主地图和历史成果，进度区始终跟随当前任务。

生成按钮旁和进度区均有“暂停生成”。点击后先显示“暂停中”，等当前下载分块或计算步骤结束后变为“已暂停”；在暂停生效前可以“撤销暂停”。点击“恢复生成”会继续同一进程中的任务，保留已完成的计算和下载。已暂停期间进度和生成用时保持不变，暂停时间不消耗 OSM 下载预算。较长的建筑下载或单步地形计算可能需要等到该步骤完成才能暂停。

暂停控制文件被短暂占用时会进行有限重试；持续不可读时明确报错。取消失败后会按工作进程已确认的实际状态恢复按钮，避免一直显示“暂停中”或“恢复中”。

“停止并取消”会终止计算及网络下载，已暂停的任务也可以直接取消；取消后保留日志，不标记成功。暂停仅在本次软件会话内有效，关闭软件会询问是否取消当前任务；取消并退出后不能跨重启接续计算，重新生成仍可复用保留的完整下载缓存。

左下角“清除缓存”可分别查看和清理基础数据/计算缓存、地图缓存，默认仅选择基础数据。清理保留已生成的模型、图层、日志、历史和地图位置。生成、暂停或取消处理中不可清理，需先完成或停止任务。清理后新任务需要重新下载，地图缓存清理后当前已显示的底图可暂时保留，后续请求会重新获取。

## 数据与成果

- 默认成果目录：软件文件夹下 `data`；软件目录不可写时会提示选择其他目录。
- 每个任务独立保存配置、完整日志和结果。已完成的同范围基础数据可复用。
- 复用时忽略空文件，并检查道路、河流缓存的 JSON 和节点连接结构。损坏共享缓存不会覆盖完整历史输入；没有有效输入时重新下载。删除项目并保留缓存时，可用完整输入修复损坏的共享缓存。如果没有有效共享副本且原始输入损坏，保留缓存的删除操作会明确报错并保留项目。栅格和建筑文件的完整 GIS 内容仍由计算阶段读取检查。
- 新版不再自动导入南京示例，主地图默认不显示任何项目。删除的成果不会在重启后自动恢复。
- 重命名只改变项目显示名称，保留项目编号和成果路径。删除时未勾选清除缓存，会先保留该项目已确认完整的下载阶段到共享缓存，不保留下载到一半的文件。缓存是跨项目共享的：勾选“是否同时清除缓存”会清除全部基础数据下载/计算缓存（包括其他历史项目中的原始下载），不删除其他项目已生成的管网成果，也不清除底图缓存。正在被另一个任务复用的项目，需等该任务结束再删除。
- `.inp` 导出会同时复制 `storm.dat`；ZIP 内也含相对引用的降雨文件，可整体搬迁。
- 历史任务和成果使用相对路径；复制整个软件文件夹即可携带默认目录下的历史任务。
- 百分比是阶段进度，不是剩余时间估算。首次地形分析和在线建筑数据扫描可能较久，期间百分比不会虚增。
- 状态文件短暂被占用时会自动重试，不再因此中止计算。持续占用时先保存独立恢复记录，重启会读取最新版本；解除占用后自动写回。进度区会显示保存异常提示。如果主记录和恢复记录都无法写入，请暂勿关闭软件，先确保成果目录可写且磁盘有空间；详细原因保存在对应任务的 `state-write.log`（目录可写时）。

## 范围与限制

单次范围上限约 1000 km²，前后端统一校验。面积增大时，建筑数据扫描、OSM 分块请求、管网计算的耗时与内存占用都会增加，建议先确认小范围能够生成。经度范围 ±180°，交互地图纬度范围 ±85.051129°，不支持跨日期变更线的矩形。

2026-10-08 实测南京 999.90 km²：同一次运行完整生成约 15.3 万管段，用时约 64 分 40 秒，全部 147 份 OSM 查询重新下载；高程/建筑复用完整缓存。大范围可能需要较长时间，请根据分块编号、自动恢复说明和已用时间判断状态。该测试通过生成、导出和 SWMM 加载检查，存在汇水区几何及部分高程警告，未运行水力模拟；详细记录见随软件附带的《1000平方公里验收.md》。
高程等数据的覆盖范围可能比地图更小；没有有效道路或数据源不可达时，会明确报错并保留日志。
OSM 主服务连接异常时会自动尝试 VK Maps、Private.coffee 公开备用服务，服务地址来自 [OSM 公共实例列表](https://wiki.openstreetmap.org/wiki/Overpass_API#Public_Overpass_API_instances)。主站明确提示不超过 30 秒的短排队时，按提示等待一次并继续；遇到限流、较长排队或网关超时会检查其他服务，仍遵守该服务的冷却时间。连接超时 10 秒，每次连接一个服务最多等待 90 秒，单个分块查询（包含自动恢复）总计最多 240 秒。步行路网、行车路网和河流分别按实际分块查询数量分配下载时间：每个查询按 1 分钟计算，阶段总上限最少 8 分钟、最多 60 分钟，例如 49 份查询的阶段上限为 49 分钟。这个上限只在阶段开始时确定，不随重试不断延长，也不是预计完成时间。等待期间每约 10 秒更新中文状态，可随时停止。超过上限会报告失败，不使用不完整数据，也不虚增进度。

如果停在 25% 或 35%，请查看进度条下方的分块编号和恢复说明：这是道路或河流下载阶段，百分比不会随等待时间增加。程序会自动执行有次数上限的恢复，不必为了触发恢复而反复点击取消；“停止并取消”用于真正停止任务。任务最终失败后，可稍后重新生成；同一范围中已确认成功的下载阶段和完整 OSM 分块会复用。缓存先写临时文件，完整写入后再原子替换，避免取消时留下半份有效文件；已有损坏的缓存会忽略并重新下载。所有服务持续不可用时仍会明确失败，不会无限重试。

如果备用服务均失败，原服务已经结束排队或临时故障冷却，软件会在剩余预算内自动恢复。每个服务在同一分块中最多尝试 2 次，遵守 Retry-After 和排队时刻；状态在不同分块之间保留，避免跳过已恢复的服务。此恢复覆盖连接超时、临时连接中断及 HTTP 429/502/503/504；证书验证错误和永久 HTTP 错误不会自动反复尝试，HTTPS 证书校验保持开启。等待说明会显示在进度条下方，可以随时取消。公共 OSM 服务有共享负载及配额，程序遵守[服务端冷却规则](https://dev.overpass-api.de/overpass-doc/en/preface/commons.html)，不通过并行请求或切换网络身份规避限制。

2026-10-07 版本修正了计算模块错误继承的 OSMnx 来源标识，所有 OSM 请求统一使用真实 CNG 应用标识。大范围按约 25 km² 上限分块，逐块请求并缓存，界面显示当前分块；每次向服务器申请的执行预算降为 25 秒、64 MB，减少因资源预留过大被拒绝的情况。这是服务器执行预算，连同连接及数据传输的总等待上限见前文。

范围查询使用较短的边界框，保留原来的 500 米缓冲区、道路筛选、完整节点、裁剪和管网计算；短查询使用 GET，较长的自定义查询仍使用 POST。所有分块完整下载后才合并计算，不丢弃超时分块，也不使用不完整响应。有效查询返回“没有河流”时允许正常继续；网络失败仍会明确报错，不会被当作“没有河流”。

### 底图空白或手动启动后联网异常

底图现在由本地服务通过 HTTPS 获取，再通过本机地址交给地图显示；底图不再依赖内嵌浏览器直接访问外网。查看过的瓦片按服务端 HTTP 缓存规则保存在成果目录 `map-cache`，只下载当前视野所需图片。

左下角“网络检查”可分别查看底图、高程目录、建筑目录和 OSM 服务的连通状态。底图加载失败时，地图上方会显示具体原因，并提供“重试底图”。检查显示的是接口连通性，不能代替实际生成结果；建筑大范围扫描和 OSM 下载仍可能耗时。

连接日志保存在成果目录 `network.log`。若所有服务均失败，可先检查已有系统代理是否在运行、系统是否允许软件联网，或切换手机热点重试；软件不会自行更改系统代理、防火墙或证书设置。

成果为公开数据推导的合成排水管网，并非现状实测地下管线。第一版不包含手工管线编辑、离线数据导入或水力模拟界面。

## 开发与重建

`desktop.py` 为桌面/子进程入口；`app.py` 为本地任务服务；`web` 为交互界面。
`vendor/swmmanywhere-src` 是用户提供的 SWMManywhere 源码副本，增加可选进度回调，保留 CLI 调用方式。

使用 Python 3.12 建立 `.venv-build`，安装 `requirements-lock.txt`，准备 `native` 后执行 `build.ps1`。新版打包不再包含历史示例成果。
构建资源版本、许可证见 `_internal/licenses`；固定 WebView2 不会自动更新，发布新版时应更新运行时。
源代码环境可执行 `.venv-build\Scripts\python.exe desktop.py`；测试执行 `python -m pytest tests -q`。
